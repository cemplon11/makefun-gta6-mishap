competition on [make.fun](https://make.fun).

## What it does

`main.py` (pure Python stdlib) writes one sentence — at most 240 characters —
to `/output/entry.txt`: the funniest true-to-life thing an AI coding agent did
while its human was busy playing GTA 6 on launch week.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
